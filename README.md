# SoundTool

**SFX 와 BGM** 을 명령줄로 만들어 주는 툴이다. SFX 는 rfxgen, BGM 은 mido → FluidSynth → GeneralUser GS 로 굽는다.

**상태 : 조사 끝 · 바로 착수 가능** (그림 쪽 미정 사항을 안 기다려도 된다)
