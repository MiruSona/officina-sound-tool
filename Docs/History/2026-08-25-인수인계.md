## 밟은 함정 (다음에 또 걸리지 않게)

- **rfxgen 은 잘못된 `.rfx` 에도 exit 0 으로 3프레임 무음 WAV 를 낸다.** 프레임 수로 판정한다. `--help` 의 "32bit" 는 거짓, 실제 16bit.
- **FluidSynth 는 MIDI 끝에서 안 멈추고 3.03초 고정 꼬리를 붙인다** (`-R 0 -C 0` 이어도). 그래서 모든 곡을 자른다. `-g` 기본 0.2 는 너무 작다(피크 −21 dBFS), 1.35 로 확정.
- 정상 BGM 도 4kHz 위 에너지가 0.06~1.9% 라 대역 문턱 「고 2%」는 전부 떨어뜨린다 → 0.02%.
- 루프 이음매를 끝/첫 50ms RMS **비**로 재면 정상 곡도 0.137 로 떨어진다 → 각각 무음 아님(≥ −45 dBFS)만 본다.
- Windows PowerShell 에서 한글 출력이 깨지면 `PYTHONIOENCODING=utf-8`.
- 공수 눈금 : **설계가 표·시그니처까지 정한 코드 구현은 사람 눈금 ×0.1. 실측이 든 소단계는 안 줄어든다.** (`Docs/History/공수기록.md`)
